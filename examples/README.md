# Примеры

Скопируйте папку `Хранилище` **за пределы репозитория** и откройте копию в Veltrite. В ней есть связанные заметки, шаблон, дневник, холст и база с несколькими представлениями. Все записи вымышлены и предназначены для знакомства с приложением.

`расширение.json` — пример декларативного расширения. Его можно установить через **Настройки → Расширения** и отдельно включить. Оно добавляет команды в палитру; JavaScript не исполняется.
