# Начало

Это пример хранилища: заметки, холст и база в одной папке.

## Файлы и ссылки

Откройте [[Проекты/Сайт|план сайта]] или [[Справочник/Ссылки между заметками|справку по ссылкам]]. Папки и имена файлов сохраняются при импорте.

| Клавиши      | Действие        |
| :----------- | :-------------- |
| ⌘ / Ctrl + N | Новая заметка   |
| ⌘ / Ctrl + O | Перейти к файлу |
| ⌘ / Ctrl + E | Правка / чтение |
| ⌘ / Ctrl + P | Команды         |
