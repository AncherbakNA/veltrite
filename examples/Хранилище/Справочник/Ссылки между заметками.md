# Ссылки между заметками

Ссылка записывается как `[[Название]]`. Для другой подписи используйте `[[Название|подпись]]`.

## Папки

Полный путь помогает выбрать нужный файл при одинаковых именах: [[Проекты/Сайт]].

## Разделы и вложения

Для ссылки на раздел добавьте `#Заголовок`. Изображение вставляется как `![[Вложения/схема.png]]`.

Обратные ссылки доступны в правой панели заметки.
