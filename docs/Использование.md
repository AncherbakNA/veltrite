# Использование Veltrite

Слева находятся **Главная**, **Граф знаний** и **Сегодня**. Меню **+** создаёт заметку, холст, базу или папку. Название хранилища открывает меню с переключением, созданием, открытием папки и импортом её копии. Импорт также доступен в **Настройки → Редактор**.

Ряд иконок ниже навигации переключает файлы, поиск, закладки и теги. Кнопка фильтра в заголовке дерева выбирает тип файлов и открывает соответствующую коллекцию. Открытые вкладки сохраняются при переходах между разделами.

В строке документа находятся путь, переключение правки и чтения, закладка и меню **⋯**. Исходный код и предпросмотр рядом доступны в этом меню. Правая панель содержит сворачиваемые разделы содержания, ссылок, свойств и сносок; переключатель панели находится справа в строке вкладок.

Настройки находятся внизу слева. Запись аудио запускается из палитры команд. Состояние сохранения обозначено точкой внизу; сообщения появляются при изменениях или ошибках. Кнопка обмена открывает настройки GitHub, если синхронизация ещё не подключена.

## Горячие клавиши

| Комбинация         | Действие                |
| ------------------ | ----------------------- |
| ⌘/Ctrl + N         | Новая заметка           |
| ⌘/Ctrl + O         | Быстрый переход         |
| ⌘/Ctrl + P         | Палитра команд          |
| ⌘/Ctrl + S         | Сохранить               |
| ⌘/Ctrl + Shift + S | Синхронизировать        |
| ⌘/Ctrl + E         | Чтение / редактирование |
| ⌘/Ctrl + Shift + F | Поиск по хранилищу      |
| ⌘/Ctrl + F         | Поиск внутри редактора  |
| ⌘/Ctrl + ,         | Настройки               |

В режиме исходного кода Markdown остаётся полностью видимым. В редакторе маркеры оформления и wiki-ссылки сворачиваются на строках вне курсора. В чтении показываются вложения, формулы и диаграммы.

На пустой строке редактора `/` открывает палитру команд. Escape оставляет введённый символ; выбор команды удаляет его. Наведение на wiki-ссылку в режиме чтения показывает фрагмент заметки.

## Холст

Создайте холст через **+ → Новый холст** или палитру команд. Верхняя панель добавляет текст, существующий файл, ссылку и группу. Кнопка **Связь** включает соединение: выберите начальную и конечную карточку.

Перетаскивайте карточки за заголовок; нижний правый угол меняет размер. Shift позволяет выбрать несколько карточек. Delete удаляет выбранное. ⌘/Ctrl + C и V копируют карточки внутри открытого холста. ⌘/Ctrl + Z отменяет действие. Прокрутка перемещает холст; ⌘/Ctrl + прокрутка изменяет масштаб.

## История и корзина

В палитре доступны **История версий заметки** и **Открыть корзину**. Перед заменой содержимого создаётся локальная версия; хранится до 50 версий на файл. Восстановление прежней версии само создаёт запись для текущего текста.

## Публикация

Команда **Опубликовать базу знаний: экспорт сайта** создаёт статические HTML-страницы и вложения в отдельной пустой папке. Их можно разместить на GitHub Pages или любом статическом хостинге. Команда сама ничего в интернет не отправляет.

Публикация делает выбранное содержимое открытым после загрузки на хостинг. Шифрование GitHub Sync относится к приватному обмену и не применяется к экспортированному сайту.
