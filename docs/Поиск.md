# Поиск

Откройте «Поиск» в левой панели или нажмите `⌘/Ctrl Shift F`.

| Запрос                           | Результат                                           |
| -------------------------------- | --------------------------------------------------- |
| `план`                           | Совпадение в тексте или пути                        |
| `"красный мост"`                 | Точная фраза без учёта регистра                     |
| `tag:проект`                     | Тег `проект` и вложенные теги                       |
| `path:Работа file:План`          | Папка и имя файла                                   |
| `title:План`                     | Заголовок или псевдоним заметки                     |
| `content:срок`                   | Только содержимое                                   |
| `(план OR задача) NOT tag:архив` | Группа альтернатив с исключением                    |
| `[status: active] [rating:>=3]`  | Свойство и числовое сравнение                       |
| `[deadline]`                     | Наличие свойства                                    |
| `content:/мост \d+/iu`           | Регулярное выражение с Unicode и без учёта регистра |

Пробел между условиями означает `AND`. Приоритет: `NOT` и `-`, затем `AND`, затем `OR`. Для другой последовательности используйте круглые скобки. Поля `path`, `file`, `title`, `content` и `tag` принимают фразу в кавычках или регулярное выражение. Поддержаны флаги `i`, `m`, `u`; замена текста этим поиском не выполняется.

У свойств доступны `=`, `!=`, `>`, `<`, `>=`, `<=`; неравенства сравнивают числа. Без оператора ищется подстрока, для списка — хотя бы один элемент.

Поиск показывает до 500 совпадений, не более пяти строк на файл. Регулярные выражения выполняются в отдельном процессе. Слишком долгий запрос прерывается с объяснением, следующий запрос можно выполнить сразу.
