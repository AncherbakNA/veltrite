# JavaScript-расширения

Расширение состоит из `manifest.json` и `main.js`. Выберите манифест в настройках → «Расширения» → «Установить расширение». Установка оставляет его выключенным. При включении приложение показывает запрашиваемые разрешения. Обновление пакета сбрасывает подтверждённые разрешения.

```json
{
  "id": "example",
  "name": "Пример",
  "description": "Вставка текста",
  "version": "1.0.0",
  "apiVersion": 1,
  "main": "main.js",
  "permissions": ["editor.write"],
  "commands": [{ "id": "insert", "name": "Вставить строку" }]
}
```

```js
export default async function activate(api) {
  await api.commands.register("insert", () => api.editor.replaceSelection("Текст"));
  return () => {
    /* Освобождение собственных ресурсов перед отключением. */
  };
}
```

Доступны [декларации TypeScript](../sdk/veltrite.d.ts) и примеры [даты и времени](../catalog/extensions/timestamp/) и [содержания](../catalog/extensions/outline/).

| Разрешение     | API                                                                   |
| -------------- | --------------------------------------------------------------------- |
| `vault.read`   | `vault.list()`, `vault.read(path)`, событие `vault:changed`           |
| `vault.write`  | `vault.create(path, content)`, `vault.write(path, content, revision)` |
| `editor.read`  | `editor.get()`, событие `editor:changed`                              |
| `editor.write` | `editor.replaceSelection(text)`, `editor.append(text)`                |
| `storage`      | `storage.get(key)`, `storage.set(key, value)`                         |
| `notice`       | `notice(text)`                                                        |

`vault.read()` возвращает путь, содержимое и ревизию. Для изменения существующего файла передайте полученную ревизию. Если файл успел измениться, запись отклоняется. Пути относительны открытому хранилищу; служебные папки и выход за его границы недоступны. Разрешения действуют в приложении при переключении между хранилищами.

`editor.get()` возвращает текущий черновик, выделение и путь; текст и выделение ограничены первым 1 МиБ символов. `replaceSelection` вставляет текст в активную панель, `append` добавляет текст в конец без автоматического переноса строки. Вставка доступна для Markdown-заметок.

`commands.register(id, handler)` регистрирует команду, объявленную в манифесте. Команда появляется в палитре. Функция активации может вернуть обработчик отключения; альтернативно используйте `onUnload`. `on(event, callback)` возвращает функцию отписки. Перед отключением обработчики получают до 500 мс; затем процесс завершается. Хранилище настроек отдельное для каждого расширения, до 256 КиБ JSON, значения не шифруются. Секреты в него сохранять не следует.

Код исполняется в отдельном изолированном renderer без Node.js, доступа к API основного окна, файловой системе, сети и системным разрешениям. Активация и команда ограничены пятью секундами. Зависшая команда отключает своё расширение. Одновременно доступны до восьми JavaScript-расширений. Пакет содержит один модуль ESM; зависимости нужно заранее собрать в `main.js`.

API Veltrite имеет собственный формат. Совместимость с чужими исполняемыми расширениями не заявляется. Старые JSON-команды `insert`, `create`, `open-url` продолжают работать.
