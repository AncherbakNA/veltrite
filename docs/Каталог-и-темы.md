# Каталог и темы

В настройках доступны каталог расширений и темы оформления. Каталог поставляется с приложением и работает без сети. «Обновить каталог» получает список из публичного репозитория Veltrite. Вход в GitHub для этого не нужен.

При установке проверяются размер и SHA-256 каждого файла. Список указывает на версию пакета в конкретном теге релиза. Неполная загрузка или несовпадение контрольной суммы отклоняется. При недоступности обновления каталога сохраняется доступ к встроенному списку.

Расширение устанавливается выключенным. При включении запрашиваются объявленные разрешения. Обновление сбрасывает подтверждение разрешений. Удаление через настройки убирает расширение и его собственные настройки; заметки остаются в хранилище.

Темы содержат цвета, светлый и тёмный варианты. Выбор светлого, тёмного или системного режима работает независимо от выбранной палитры. Тему можно установить из каталога либо импортировать из JSON. Кнопка «Стандартная палитра» возвращает обычное оформление. Выбранная палитра сохраняется в настройках хранилища.

Для создания темы используйте [пример «Сланец»](../catalog/themes/slate/theme.json). Поддержаны только цвета `#RRGGBB` и фиксированные токены: `bg`, `panel`, `sidebar`, `ribbon`, `surface`, `hover`, `border`, `border-strong`, `text`, `muted`, `faint`, `green`, `red`. CSS, HTML, скрипты и удалённые шрифты из темы не загружаются. Текстовые цвета проверяются на контраст не ниже 4,5:1 на всех поверхностях. Цвет текста акцентных ссылок подбирается с учётом палитры.

Метаданные каталога находятся в `catalog/index.json`, исходники пакетов — в `catalog/extensions` и `catalog/themes`. После изменения пакетов выполните `node scripts/catalog.mjs`. Форматирование через рабочий скрипт также пересчитывает контрольные суммы. Каталог должен ссылаться на уже опубликованный тег; до публикации нового релиза локальная установка использует встроенные файлы.
