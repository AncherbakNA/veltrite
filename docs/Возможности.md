# Возможности и ограничения

Ниже перечислено поведение текущей версии. Поддержка формата файла не означает поддержку всех его расширений.

| Область                  | Реализовано                                                                                                | Границы                                                                                                                                               |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Markdown                 | Живое оформление заголовков, задач, ссылок, таблиц, формул и диаграмм; исходный код, чтение, режим рядом   | Блоки переключаются в исходный текст кнопкой «Править» или двойным щелчком                                                                            |
| Формулы и диаграммы      | KaTeX и Mermaid                                                                                            | Не все сторонние синтаксические расширения                                                                                                            |
| Файлы                    | Папки, вкладки, импорт, переименование, корзина                                                            | Только переносимые имена, без символических ссылок                                                                                                    |
| Ссылки                   | Wiki-ссылки, псевдонимы, относительные ссылки, вложения, переходы и встраивание заголовков и блоков `#^id` | ID блока задаётся явно; идентификаторы сторонних расширений не вычисляются                                                                            |
| Индекс                   | Поиск, теги, свойства, содержание, исходящие и обратные ссылки                                             | Текст, фразы, поля, AND/OR/NOT, группы, свойства и regex с ограничением времени; до 500 результатов, несвязанные упоминания отдельно не индексируются |
| Предпросмотр страницы    | Предпросмотр wiki-ссылок в редакторе и чтении; ссылка на блок показывает выбранный фрагмент                | При редактировании самой ссылки доступен её исходный текст                                                                                            |
| Slash-команды            | `/` на пустой строке открывает палитру и удаляется после выбора                                            | Без настраиваемых меню отдельных плагинов                                                                                                             |
| Граф                     | Общий и локальный граф, фильтр, открытие узлов                                                             | Все заметки участвуют в графе; расчёт в worker, для более 1000 узлов — Canvas. Не все настройки физики и групп                                        |
| Холсты                   | JSON Canvas: текст, файлы, изображения, ссылки, группы, связи, цвет, размер, масштаб, копирование и отмена | Веб-карточки открываются по нажатию в изолированном просмотре; до четырёх одновременно. Сторонние поля сохраняются в JSON                             |
| Bases                    | Таблицы, карточки, список, канбан, карты; типы свойств, сортировка, фильтры, формулы и итоги               | Ограниченный интерпретатор формул, без произвольного JavaScript. Карты по координатам; подложка требует сети                                          |
| Свойства                 | YAML, редактирование свойств текущей заметки                                                               | В базе доступны восемь типов; схема хранится в файле базы и применяется при правке её ячеек                                                           |
| Повседневные инструменты | Ежедневные и уникальные заметки, шаблоны, закладки, случайная заметка, палитра команд, Vim                 | Закладки пока на файлы; шаблоны поддерживают `date`, `time`, `title`                                                                                  |
| Работа с заметками       | Создание из выделения, объединение, история, сноски                                                        | Выделение копируется в новую заметку; автоматическое извлечение с заменой ещё не реализовано                                                          |
| Наборы вкладок           | Сохранение вкладок, дерева панелей, размеров и режимов                                                     | До 16 панелей и 8 уровней; один файл в нескольких панелях использует общий черновик                                                                   |
| Публикация               | Экспорт HTML, PDF и статического сайта                                                                     | Экспорт в локальную папку; загрузка на хостинг выполняется отдельно                                                                                   |
| Синхронизация            | Собственный зашифрованный формат через личный GitHub                                                       | Обмен проверен на двух синтетических клиентах; ручная приёмка с реальным пользовательским репозиторием ещё не проведена                               |
| Расширения               | JSON-команды и JavaScript API 1 с разрешениями и изолированным окружением                                  | До восьми JS-расширений, команда до 5 секунд; свой API. Каталог расширений и тем в работе                                                             |
| Аудио и веб              | Запись в заметку, отдельный изолированный веб-просмотр                                                     | Нативная запись требует разрешения микрофона и отдельной ручной приёмки                                                                               |
| Обновления               | Проверка версии и переход к установщику релиза                                                             | Бесшовная замена приложения ещё не реализована                                                                                                        |

Таблица описывает текущую версию. Неподдерживаемые выражения и повреждённые документы не должны приводить к перезаписи исходного файла.

Формат холстов: [JSON Canvas 1.0](https://jsoncanvas.org/spec/1.0/).
