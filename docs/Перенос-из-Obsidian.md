# Перенос из Obsidian

Есть два способа начать работу с существующим хранилищем.

## Открыть папку

Выберите **Открыть папку** и укажите папку хранилища Obsidian. Veltrite будет работать с теми же файлами и создаст служебную папку `.veltrite`. Правки заметок будут видны в обеих программах.

Если файл изменится во внешнем редакторе, Veltrite проверит его ревизию перед сохранением. При конфликте несохранённый текст останется в редакторе; его можно записать отдельной копией.

## Импортировать копию

Выберите **Импорт из Obsidian**, укажите исходное хранилище и отдельную пустую папку назначения. Исходная папка не изменяется.

Импорт сохраняет:

- вложенные папки и имена заметок;
- Markdown и YAML-свойства без переписывания содержимого;
- изображения, PDF, аудио, видео и другие файлы;
- wiki-ссылки, обычные Markdown-ссылки, теги и псевдонимы в тексте;
- файлы `.canvas` и `.base` с исходными байтами.

Из настроек Obsidian переносятся поддерживаемые пути папок вложений, ежедневных заметок и шаблонов. Специальные режимы вроде «в папке текущей заметки» пока оставляются по умолчанию и отмечаются в предупреждении.

`.obsidian`, `.git`, `.trash` и другие скрытые каталоги не копируются в рабочее содержимое. Сторонние плагины, их секреты и исполняемый код не запускаются. При наличии плагинов импорт сообщает об этом.

## Имена и символические ссылки

Для общего хранилища Mac и Windows используются переносимые имена. Зарезервированные имена Windows (`CON`, `NUL` и другие), запрещённые символы, имена с точкой или пробелом на конце и конфликты регистра отмечаются как пропущенные. Символические ссылки также пропускаются. Отчёт показывает эти пути; оригиналы остаются в исходной папке.

Сначала попробуйте импорт копии и проверьте отчёт. Для полного совпадения сложного хранилища учитывайте [ограничения совместимости](Совместимость.md).
