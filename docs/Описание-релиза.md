Veltrite 0.3.0 для macOS и Windows.

- Новый спокойный медный акцент: светлее на графитовых поверхностях и глубже на бумажных; приглушённые природные оттенки в настройках.
- Разделение документов вправо и вниз: независимые режимы, общий черновик одного файла, сохранение размеров и расположения.
- Таблицы, KaTeX и Mermaid прямо в режиме правки; переходы к заголовкам и блокам, встраивание фрагментов и предпросмотр ссылок.
- Поиск с AND/OR/NOT, группами, полями, свойствами и регулярными выражениями. Долгие запросы прерываются отдельно от интерфейса.
- Базы: восемь типов свойств, формулы списков и дат, 15 видов итогов и свои агрегаты; карты с координатами и необязательной сетевой подложкой.
- Изолированные веб-карточки на холсте. Обзор больших холстов, Canvas-граф для тысяч заметок, компактное дерево и страницы больших таблиц.
- JavaScript API 1: разрешения, отдельный процесс расширения, команды, события, редактор, файлы и собственные настройки. Каталог тем и расширений, установка, отключение и удаление.
- Проверка и загрузка обновлений с SHA-512. Windows устанавливает новую версию после сохранения черновиков. Mac без сертификата издателя открывает страницу установщика.
- Исправлены переходы между соседними панелями, уникальные адреса повторяющихся заголовков, ожидание готовности редактора при вставке из расширения и работа при частых изменениях файлов.

Установщики: Mac ARM64, Mac x64 и Windows x64. SHA-256 — в `SHA256SUMS.txt`; ленты обновлений включают обе архитектуры Mac. Сертификатов издателя пока нет: Mac использует ad-hoc подпись целостности; Developer ID, нотарификация Apple и подпись Windows подготовлены как отдельный строгий режим сборки.

[Возможности и ограничения](https://github.com/AncherbakNA/veltrite/blob/main/docs/Возможности.md) · [Установка и обновления](https://github.com/AncherbakNA/veltrite/blob/main/docs/Установка-и-обновления.md) · [Расширения](https://github.com/AncherbakNA/veltrite/blob/main/docs/Расширения.md).

Реальная приёмка GitHub Sync и настройка браузерного входа в этот выпуск не входили. Нативное разрешение и качество записи микрофона требуют ручной проверки; автоматический сценарий использует синтетический аудиопоток.
