Первая рабочая версия Veltrite для локальных Markdown-хранилищ, визуальных холстов и зашифрованной синхронизации через личный приватный GitHub-репозиторий.

Включены редактор, чтение, ссылки, теги, поиск, граф, свойства, таблицы и другие представления Bases, импорт Obsidian, история и корзина.

Это ранняя версия. Полный API плагинов Obsidian, отдельные расширенные режимы и бесшовные обновления ещё не реализованы. Перед работой с единственной копией данных используйте импорт копии. Подробности — в таблице совместимости репозитория.

Выберите установщик для своей ОС и архитектуры. Контрольные суммы приведены в `SHA256SUMS.txt`. Mac-сборки используют ad-hoc подпись; подписи издателя Apple и Windows пока не настроены.
