Veltrite 0.2.1 для macOS и Windows.

Изменения интерфейса:

- Верхняя строка вкладок и поиск файлов через ⌘/Ctrl + O.
- Компактная панель документа: правка и чтение через ⌘/Ctrl + E, исходный код и режим «Рядом» в меню ⋯.
- Главная с недавними файлами и закладками; коллекции в виде таблиц.
- Меню «+» для создания файлов; импорт в меню хранилища и настройках редактора.
- Сворачиваемые разделы справа: содержание, обратные ссылки, свойства и сноски.
- Графитовая и бумажная темы, шесть акцентных цветов и собственный цвет, локальный Source Serif 4 с кириллицей.
- Выбор шрифта текста и стартового экрана; менее заметное состояние сохранения.
- Приглушённые рамки карточек холста, короткие имена файлов и читаемые подписи связей.
- Системное уменьшение движения учитывается и при переходе к заголовкам; экспорт сайта использует бумажную тему.

Markdown, ссылки, граф, свойства, импорт структуры папки, история, корзина и зашифрованная синхронизация через отдельный личный приватный репозиторий GitHub сохранены.

Ранняя версия. Ограничения формул баз, расширений и других инструментов перечислены в [документации](https://github.com/AncherbakNA/veltrite/blob/main/docs/Возможности.md). Обмен проверен на синтетических клиентах; ручная приёмка реальной синхронизации и записи микрофона ещё не завершена.

Установщики доступны для Mac ARM64, Mac x64 и Windows x64; контрольные суммы — в `SHA256SUMS.txt`. Mac-сборки подписаны ad-hoc. Developer ID, нотарификация Apple и подпись издателя Windows пока не настроены.
