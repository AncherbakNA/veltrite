# Совместимость и границы реализации

Цель — самостоятельная база знаний с основными инструментами Obsidian и обычными файлами. Наличие похожей кнопки не означает полную совместимость с соответствующим API.

| Область                  | Реализовано                                                                                                | Границы                                                                                                                       |
| ------------------------ | ---------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Markdown                 | Редактор, живое оформление, исходный код, чтение, режим рядом                                              | Живое оформление пока не воспроизводит каждый элемент Live Preview Obsidian                                                   |
| Формулы и диаграммы      | KaTeX и Mermaid                                                                                            | Не все сторонние синтаксические расширения                                                                                    |
| Файлы                    | Папки, вкладки, импорт, переименование, корзина                                                            | Только переносимые имена, без символических ссылок                                                                            |
| Ссылки                   | Wiki-ссылки, псевдонимы, обычные относительные ссылки, вложения                                            | Часть сложных ссылок на блоки и автоматических преобразований требует развития                                                |
| Индекс                   | Поиск, теги, свойства, содержание, исходящие и обратные ссылки                                             | Поиск пока без полного языка запросов Obsidian; несвязанные упоминания отдельно не индексируются                              |
| Предпросмотр страницы    | Содержимое заметки при наведении на wiki-ссылку в чтении                                                   | В редакторе пока обычная подсказка                                                                                            |
| Slash-команды            | `/` на пустой строке открывает палитру и удаляется после выбора                                            | Без настраиваемых меню отдельных плагинов                                                                                     |
| Граф                     | Общий и локальный граф, фильтр, открытие узлов                                                             | Ограничен 500 видимыми заметками; не все настройки физики и групп                                                             |
| Холсты                   | JSON Canvas: текст, файлы, изображения, ссылки, группы, связи, цвет, размер, масштаб, копирование и отмена | Веб-карточки открывают сайт отдельно; дополнительные поля сторонних расширений сохраняются в JSON                             |
| Bases                    | Таблицы, карточки, список и канбан; свойства, сортировка, фильтры и основные формулы                       | Поддерживается подмножество языка формул; нет карт, всех агрегатов и сторонних функций. Неизвестные выражения явно отмечаются |
| Свойства                 | YAML, редактирование свойств текущей заметки                                                               | Нет полной схемы типов свойств; ячейки свойств заметок можно редактировать двойным щелчком                                    |
| Повседневные инструменты | Ежедневные и уникальные заметки, шаблоны, закладки, случайная заметка, палитра команд, Vim                 | Закладки пока на файлы; шаблоны поддерживают `date`, `time`, `title`                                                          |
| Работа с заметками       | Создание из выделения, объединение, история, сноски                                                        | Выделение копируется в новую заметку; автоматическое извлечение с заменой ещё не реализовано                                  |
| Рабочие пространства     | Сохранение и открытие вкладок                                                                              | Без произвольного дерева разделённых панелей                                                                                  |
| Публикация               | Экспорт HTML, PDF и статического сайта                                                                     | Не подключается к платному сервису Obsidian Publish                                                                           |
| Синхронизация            | Собственный зашифрованный формат через личный GitHub                                                       | Не подключается к Obsidian Sync; независимая проверка на реальном репозитории нужна перед публичным выпуском                  |
| Расширения               | Декларативные JSON-команды Veltrite                                                                        | Полного API `obsidian`, магазина тем и совместимости со всеми JavaScript-плагинами нет                                        |
| Аудио и веб              | Запись в заметку, отдельный изолированный веб-просмотр                                                     | Нативная запись требует разрешения микрофона и отдельной ручной приёмки                                                       |
| Обновления               | Проверка версии и переход к установщику релиза                                                             | Бесшовная замена приложения ещё не реализована                                                                                |

Таким образом, требование «весь функционал Obsidian» пока **не закрыто**. Эта таблица — список явных оставшихся различий, а не заявление о завершённом клоне.

Основа перечня: [основные плагины Obsidian](https://obsidian.md/help/plugins), [JSON Canvas 1.0](https://jsoncanvas.org/spec/1.0/).
