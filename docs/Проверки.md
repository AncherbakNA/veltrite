# Проверки Veltrite 0.3.0

Проверки выполняются на синтетических данных, с отдельными профилями, без реальных заметок, токенов синхронизации и микрофона. Зависимости, установщики, журналы и полные отчёты находятся вне исходников.

## Поведение приложения

В набор входят 90 модульных проверок и 38 сценариев настоящего Electron: редактирование и сохранение, перезапуск, конфликт внешней правки, импорт папок и вложений, холсты, базы и итоги, поиск, панели, темы, расширения и их разрешения, обновления и проверка контрольной суммы. Запись аудио проверяется синтетическим потоком. Повторные переключения редактора проверяются на отсутствие роста количества CSS-правил.

[Проверки на Mac ARM64, Intel Mac и Windows x64](https://github.com/AncherbakNA/veltrite/actions/runs/43216647972).

## Установка и обновление

На Mac проверяются установка из DMG в отдельную временную папку, целостность подписи, версия и архитектура установленного приложения, затем весь набор Electron-сценариев.

На Windows проверяются установка опубликованной 0.2.1 с проверкой SHA-256, сохранение заметки, обновление текущим установщиком и весь набор Electron-сценариев. Затем приложение загружает через локальный сервер реальный NSIS-кандидат с отдельной тестовой версией, проверяет SHA-512, устанавливает его и завершается. Проверка сверяет версию и app.asar установленного кандидата, открывает его и проверяет заметки. Удаление приложения должно сохранить профиль и заметки.

[Нативная приёмка трёх установленных пакетов](https://github.com/AncherbakNA/veltrite/actions/runs/43216647756) завершилась успешно: 38 сценариев Electron на каждой платформе, полный цикл Windows с настоящим NSIS-обновлением и сохранением данных после удаления.

Кандидат обновления не публикуется. Mac без Developer ID использует ручную замену из DMG; испытание автоматического обновления подписанного Mac-пакета требует сертификата и нотарификации.

## Нагрузка

Замеры на Apple M1 Pro, 12 ноября 2026 года. Файлы создаются генератором `scripts/benchmark.ts`; поиск проходит по всему хранилищу и проверяет десять совпадений в конце набора. Для 40 000 заметок параллельно работал отдельный сеанс приложения. Это разовые наблюдения, а не гарантированная скорость на любом диске.

| Операция                  | 10 000 заметок | 40 000 заметок |
| ------------------------- | -------------: | -------------: |
| Холодный индекс           |        1,126 с |        5,126 с |
| Повторный индекс          |        0,175 с |        0,650 с |
| Повторный поиск           |        0,508 с |        6,795 с |
| Построение связей графа   |        0,036 с |        0,154 с |
| Индекс после одной правки |        0,167 с |        0,665 с |

Отдельные интерфейсные сценарии открывают холст на 5000 карточек и граф на 1602 заметки. После правки холста проверяется сохранение всех карточек и неизвестных полей JSON. В больших коллекциях и базах на экране до 200 строк; итог проверяется по всем 501 отфильтрованным заметкам.

## Длительный сеанс

Повторный сеанс продолжался 601 секунду и завершил 489 циклов без ошибок renderer. Сценарий использует 1500 заметок и холст на 5000 карточек, многократно открывает и закрывает документы и панели, показывает таблицы, формулы и Mermaid, открывает базу и граф, выполняет команды расширения и переинициализирует его. Память JS после принудительной сборки мусора, CSS-правила, окна, процессы и DOM измеряются каждые 30 секунд. В конце успешно проверены содержимое всех 1500 заметок и неизменность холста.

Память JS после GC: 16,9 МиБ в первом замере, 23,4 МиБ в последнем, максимум 24,9 МиБ. Число CSS-правил оставалось равным 1058 во всех 21 замерах; окон — 2 (основное и расширение), процессов — 5. Рост CSS при повторном монтировании предотвращён общим экземпляром темы редактора. Этот результат относится к указанному сценарию и длительности, а не к любому содержимому хранилища.

## Границы приёмки

Сертификатов издателя пока нет. Mac имеет ad-hoc подпись целостности, Windows собирается без подписи издателя. Подключение Developer ID, нотарификации и Windows-сертификата подготовлено и требует отдельной приёмки после их получения. Системное разрешение и качество реального микрофона проверяются вручную. Реальная синхронизация GitHub и настройка браузерного входа не входили в эту работу. Десятиминутный сеанс не является суточным испытанием.
