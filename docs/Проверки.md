# Проверки Veltrite 0.4.0

Используются синтетические хранилища и отдельные профили. Реальные заметки, ключи синхронизации и микрофон в автоматических проверках не участвуют. Проверка системного буфера обмена запускается только на одноразовых CI-агентах. Зависимости, установщики, журналы и отчёты находятся вне исходников.

## Локальные результаты

На Mac M1 Pro выполнены проверка типов и 117 модульных проверок. Сценарии переходов PDF, просмотра/правки холста и создания ссылок из упоминаний дополнительно повторены четыре раза: 12 успешных запусков. Сценарий создания, свойств, истории, корзины и восстановления дополнительно прошёл четыре раза; переход к следующей команде ждёт завершения диалога удаления. Проверка системного буфера обмена выполняется только в CI. Формулы и типы дат дополнительно проверены в часовых поясах America/Los_Angeles и Asia/Tokyo: по 21 успешной проверке.

Набор охватывает сохранение и перезапуск, внешнюю правку и ревизии, импорт структуры и настроек, перенос файлов мышью, навигацию дерева, холсты, базы, общие итоги, поиск, вкладки и панели, CSS, горячие клавиши, расширения и их разрешения, запись синтетического аудио, загрузку обновления и проверку его целостности.

Для 0.4 добавлены проверки задач, выносок, сворачивания и поиска по заметке; богатых закладок; извлечения/объединения; UI настройки базы с сохранением YAML-комментариев; типизированных значений и формул; PDF, циклов вложений, встроенных баз/холстов; экспорта HTML с изображениями и шрифтами; отрисованных вложений статического сайта; PDF только выбранной панели; собственного окна расширения и переименования несохранённой заметки с сохранением закрепления.

Заведомо тяжёлое регулярное выражение базы прерывается через восемь секунд. Пока worker занят, окно настройки открывается и закрывается; исходный файл остаётся байт в байт прежним. Повторяющиеся заголовки и ID блоков проверяются при объединении в начало/конец, вместе с обратными ссылками, карточками холста и закладками. Искусственный отказ корзины проверяет откат файлов и настроек; нормализация Unicode не позволяет объединить файл с самим собой.

Скачанный из GitHub ZIP для Mac ARM64 дополнительно проверен на M1 Pro: совпали SHA-256 из API и `SHA256SUMS.txt`, SHA-512 из ленты обновлений, версия и архитектура; проверена целостность ad-hoc подписи. Из этого архива выполнен полный набор: 58 успешных сценариев и один локальный пропуск теста системного буфера. В CI этот тест включён.

## Нативные пакеты

Пайплайн собирает Mac ARM64, Mac Intel x64 и Windows x64. На Mac проверяются установка из DMG в отдельную временную папку, версия, архитектура и целостность, затем интерфейс установленного приложения. На Windows используется опубликованная базовая версия, обновление текущим NSIS-пакетом и реальная установка отдельного синтетического кандидата через обновлятор. После удаления профиль и заметки должны остаться.

[Нативная приёмка 0.4.0](https://github.com/AncherbakNA/veltrite/actions/runs/43305269944) успешно завершилась для Mac ARM64, Mac Intel x64 и Windows x64. Каждая сборка проходит типы, 117 модульных проверок и полный набор из 59 сценариев установленного приложения. Артефакты приёмки называются `Приёмка-mac-arm64`, `Приёмка-mac-x64` и `Приёмка-win-x64`; журналы и отчёты доступны в запуске. Windows дополнительно проходит обновление через NSIS и встроенный обновлятор, затем удаление с проверкой сохранности профиля и заметок.

[CI финальных исходников](https://github.com/AncherbakNA/veltrite/actions/runs/43307361195) также прошёл на Windows, Mac ARM64 и Mac Intel: типы, по 117 модульных проверок и 59 сценариев интерфейса на каждой платформе.

## Нагрузка и длительный сеанс

Воспроизводимые сценарии находятся в `scripts/benchmark.ts` и `scripts/soak.mjs`. Benchmark создаёт от 100 до 40 000 заметок, проверяет холодный/повторный индекс, поиск в конце набора, граф и индекс после правки. Интерфейсные тесты используют холст на 5000 карточек, граф на 1602 заметки и базы с несколькими страницами.

Длительный сценарий использует 1500 заметок, холст на 5000 карточек, базу, Mermaid, KaTeX, PDF отдельно и во вложениях, соседние панели, команды и переинициализацию расширения. Он измеряет память после GC, DOM, окна, процессы и количество CSS-правил, а затем сверяет содержимое всех заметок, холста и PDF. Финальный сеанс 12–13 ноября 2026 года длился 602 секунды и выполнил 427 циклов. Ошибок renderer нет; содержимое всех 1500 заметок, холста на 5000 карточек и PDF проверено. JS после GC: 18,1 МиБ в начале, 24,2 МиБ в конце, максимум 25,3 МиБ. Количество CSS-правил оставалось 1255, окон — 2 (основное и среда расширения). Это измерение JS-кучи; память процессов Electron измеряется отдельно и не равна этому числу.

Измерения 12 ноября 2026 года на Apple M1 Pro, миллисекунды:

| Операция                  | 10 000 заметок | 40 000 заметок |
| ------------------------- | -------------: | -------------: |
| Открытие и список         |            227 |            819 |
| Холодный индекс           |           1245 |           4832 |
| Повторный индекс          |            206 |            826 |
| Первый поиск              |            865 |           8460 |
| Повторный поиск           |            658 |           8397 |
| Связи графа               |             49 |            218 |
| Индекс после одной правки |            222 |            790 |

Поиск проверял десять совпадений в конце набора, граф — по одному узлу и связи на каждую заметку. Пиковый наблюдаемый RSS процесса benchmark — 262 и 577 МиБ соответственно. Это измерения синтетических Markdown-файлов на одном компьютере, а не обещание времени для любого хранилища.

## Границы

Сертификатов издателя пока нет. Mac имеет ad-hoc подпись целостности, Windows собирается без подписи издателя. Developer ID, нотарификация и Windows-сертификат требуют отдельной приёмки после подключения. Реальная пользовательская синхронизация GitHub и браузерный вход отложены. Качество физического микрофона проверяется вручную. Короткий автоматический сеанс не является суточным испытанием.
