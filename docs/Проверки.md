# Проверки Veltrite 0.4.0

Используются синтетические хранилища и отдельные профили. Реальные заметки, ключи синхронизации и микрофон в автоматических проверках не участвуют. Проверка системного буфера обмена запускается только на одноразовых CI-агентах. Зависимости, установщики, журналы и отчёты находятся вне исходников.

## Локальные результаты

На Mac M1 Pro выполнены проверка типов и 117 модульных проверок. Полный прогон интерфейса завершил 56 сценариев без ошибок; после него добавлены проверки сохранения некорректного значения без правки и системного копирования. Последняя выполняется только в CI. Формулы и типы дат дополнительно проверены в часовых поясах America/Los_Angeles и Asia/Tokyo: по 21 успешной проверке.

Набор охватывает сохранение и перезапуск, внешнюю правку и ревизии, импорт структуры и настроек, перенос файлов мышью, навигацию дерева, холсты, базы, общие итоги, поиск, вкладки и панели, CSS, горячие клавиши, расширения и их разрешения, запись синтетического аудио, загрузку обновления и проверку его целостности.

Для 0.4 добавлены проверки задач, выносок, сворачивания и поиска по заметке; богатых закладок; извлечения/объединения; UI настройки базы с сохранением YAML-комментариев; типизированных значений и формул; PDF, циклов вложений, встроенных баз/холстов; экспорта HTML с изображениями и шрифтами; отрисованных вложений статического сайта; PDF только выбранной панели; собственного окна расширения и переименования несохранённой заметки с сохранением закрепления.

Заведомо тяжёлое регулярное выражение базы прерывается через восемь секунд. Пока worker занят, окно настройки открывается и закрывается; исходный файл остаётся байт в байт прежним. Повторяющиеся заголовки и ID блоков проверяются при объединении в начало/конец, вместе с обратными ссылками, карточками холста и закладками. Искусственный отказ корзины проверяет откат файлов и настроек; нормализация Unicode не позволяет объединить файл с самим собой.

## Нативные пакеты

Пайплайн собирает Mac ARM64, Mac Intel x64 и Windows x64. На Mac проверяются установка из DMG в отдельную временную папку, версия, архитектура и целостность, затем интерфейс установленного приложения. На Windows используется опубликованная базовая версия, обновление текущим NSIS-пакетом и реальная установка отдельного синтетического кандидата через обновлятор. После удаления профиль и заметки должны остаться.

Статус приёмки 0.4 и ссылки на её отчёты будут добавлены после завершения сборок. Успех приёмки 0.3 не считается подтверждением нового пакета.

## Нагрузка и длительный сеанс

Воспроизводимые сценарии находятся в `scripts/benchmark.ts` и `scripts/soak.mjs`. Benchmark создаёт от 100 до 40 000 заметок, проверяет холодный/повторный индекс, поиск в конце набора, граф и индекс после правки. Интерфейсные тесты используют холст на 5000 карточек, граф на 1602 заметки и базы с несколькими страницами.

Длительный сценарий использует 1500 заметок, холст на 5000 карточек, базу, Mermaid, KaTeX, PDF отдельно и во вложениях, соседние панели, команды и переинициализацию расширения. Он измеряет память после GC, DOM, окна, процессы и количество CSS-правил, а затем сверяет содержимое всех заметок, холста и PDF. Результаты нового сеанса будут добавлены по его завершении; данные 0.3 не подменяют эту проверку.

## Границы

Сертификатов издателя пока нет. Mac имеет ad-hoc подпись целостности, Windows собирается без подписи издателя. Developer ID, нотарификация и Windows-сертификат требуют отдельной приёмки после подключения. Реальная пользовательская синхронизация GitHub и браузерный вход отложены. Качество физического микрофона проверяется вручную. Короткий автоматический сеанс не является суточным испытанием.
