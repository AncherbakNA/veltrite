# Разработка и устройство проекта

## Границы каталогов

В репозитории находятся исходники, тесты, конфигурация, иконки и русская документация. Рабочие файлы создаются в соседней папке `Veltrite-local`:

```text
Veltrite/                 исходники для GitHub
Veltrite-local/
  workspace/              копия для запуска, node_modules и сборка
  package/                минимальное содержимое приложения
  releases/               установщики
  cache/                  загрузки инструментов сборки
  test-results/           результаты Electron-проверок
  playwright-report/      отчёт интерфейсных проверок
  screenshots/            снимки синтетического хранилища
```

`scripts/workspace.mjs` проверяет, что рабочая папка находится вне проекта. Он не изменяет пользовательские хранилища. `scripts/tasks.mjs` запускается только внутри отмеченной рабочей копии.

## Основные модули

| Каталог или файл           | Ответственность                                                       |
| -------------------------- | --------------------------------------------------------------------- |
| `electron/main.ts`         | Жизненный цикл приложения, выбор папок, IPC и системные диалоги       |
| `electron/vault.ts`        | Файлы, история, корзина, поиск, индекс и локальные снимки             |
| `electron/paths.ts`        | Проверка относительных путей и символических ссылок                   |
| `electron/preferences.ts`  | Белый список и проверка настроек с диска и из синхронизации           |
| `electron/importer.ts`     | Импорт копии Obsidian и отчёт о пропусках                             |
| `electron/rename-links.ts` | Перенос путей и обновление ссылок                                     |
| `electron/github.ts`       | Ограниченный транспорт GitHub и Device Flow                           |
| `electron/crypto.ts`       | AES-GCM и HKDF через стандартную библиотеку                           |
| `electron/merge.ts`        | Трёхстороннее объединение без сетевых операций                        |
| `electron/sync.ts`         | Согласование состояния и атомарная публикация коммита                 |
| `electron/sync-objects.ts` | Пакеты зашифрованных объектов для уменьшения числа запросов           |
| `electron/config.ts`       | Локальная конфигурация и защищённое хранение ключей                   |
| `shared/`                  | Типы, индекс Markdown, ссылки и безопасные выражения Bases            |
| `src/useVault.ts`          | Вкладки, несохранённые правки, автосохранение и восстановление сессии |
| `src/commands.ts`          | Действия палитры команд                                               |
| `src/styles/`              | Стили оболочки, главной страницы и печати                             |
| `src/components/`          | Редактор, холсты, граф, базы, настройки и панели                      |

Интерфейс вызывает типизированный API из `shared/types.ts`. Весь прямой доступ к диску и GitHub остаётся в основном процессе. Криптография не реализует собственный шифр.

Для читаемости используйте небольшие функции с одной задачей и явные типы на границах модулей. `pnpm format` упорядочивает импорты и форматирует исходники. TypeScript проверяет неиспользуемые переменные и параметры. Проверки путей, настроек и форматов должны оставаться в общих модулях, а не дублироваться в компонентах.

## Проверки

`pnpm check` проверяет TypeScript. `pnpm test` запускает модульные и интеграционные сценарии с временными папками и синтетическим GitHub API. `pnpm test:e2e` запускает настоящий Electron с отдельным профилем.

Для проверки готового Mac-пакета можно задать `VELTRITE_EXECUTABLE` — абсолютный путь к `Veltrite.app/Contents/MacOS/Veltrite` — и запустить интерфейсные проверки из рабочей копии. Реальные заметки, токены, микрофон и системное хранилище ключей в автоматических сценариях не используются. Выбор папок при импорте подменяется только внутри тестового процесса.

Новый функционал требует проверки его поведения, а не наличия элементов интерфейса. Оставшиеся различия с Obsidian записываются в `Совместимость.md`.

## Иконки

Исходная геометрия хранится в `scripts/icons.py`. Для повторной генерации нужны Pillow и macOS `iconutil`. Папку временных изображений передавайте через `--local`, вне репозитория. Готовые `.png`, `.ico` и `.icns` — ресурсы приложения и предназначены для GitHub.

Оболочка вынесена в `AppHeader`, `Sidebar`, `DocumentToolbar`, `WorkspaceHome` и `FileCollection`. `useDialogFocus` управляет фокусом диалогов. Порядок CSS-импортов в `src/main.tsx` намеренный: правила печати подключаются последними.
