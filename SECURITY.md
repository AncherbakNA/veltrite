# Защита данных

## Локальные файлы

Заметки и вложения на диске остаются обычными файлами. Шифрование синхронизации не шифрует локальную папку. Для защиты всего компьютера используйте средства шифрования диска своей ОС.

Файловые операции ограничены выбранным хранилищем. Переходы `..`, абсолютные пути, скрытые служебные файлы и символические ссылки не принимаются через API заметок. Сохранение проверяет ревизию, чтобы не затереть внешнюю правку.

## Разделение процессов

Интерфейс Electron работает с `nodeIntegration: false`, `contextIsolation: true`, `sandbox: true`. Доступ к диску и GitHub выполняется основным процессом через ограниченный набор IPC-методов. Сырые методы Electron и произвольный `require` не передаются в интерфейс. IPC проверяет окно и основной фрейм отправителя.

В заметках не исполняется сырой HTML и JavaScript. Удалённые изображения не загружаются автоматически. Файловый протокол обслуживает поддерживаемые изображения и медиа только из выбранного хранилища. Исполняемые вложения не открываются из приложения.

Веб-просмотр использует отдельную сессию без preload и доступа к IPC хранилища. Запросы к локальным файлам и внутреннему протоколу блокируются.

## GitHub

Принимается собственный приватный репозиторий пользователя с правом записи. Запросы авторизации отправляются только в GitHub; API-запросы с токеном не следуют перенаправлениям. Проверка TLS не отключается.

Заметки, имена и структура шифруются на устройстве. Для каждого объекта используются случайная соль и nonce. Примитивы AES-GCM и HKDF предоставлены стандартной криптографической библиотекой Node.js. Ключ не выводится в логи и не отправляется в репозиторий.

Утрата ключа и всех устройств делает восстановление невозможным. Приватность репозитория сама по себе не заменяет шифрование; размеры объектов, время коммитов и активность обмена остаются видны GitHub.

Тесты транспорта используют синтетический GitHub API. До публичного выпуска необходима дополнительная проверка настоящего GitHub, Device Flow, системного хранения секретов и установки на Windows. Это не независимый аудит безопасности.
